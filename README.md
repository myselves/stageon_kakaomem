# stage-on × 카카오멤버십 요금제 전시 모바일웹 (프로토타입)

STAGEFIVE 통신 요금제(stage-on)와 카카오멤버십이 결합된 협력 모델의 요금제 전시 페이지입니다.
단일 파일(`index.html`)로 구성되어 있으며, 브라우저에서 바로 열어 확인할 수 있습니다.

## 결합 형태 (확정)
- **A안. 전 요금제 기본 내장형**: 4개 요금제 모두에 카카오멤버십(월 4,900원 상당)이 기본 포함. 단일 가격, 약정·기간 할인 없음, 평생 동일가.
- 히어로 브랜딩: 카카오멤버십 룩앤필(카카오 옐로우, 캐릭터 일러스트) 우선, stage-on은 코브랜딩 배지.

## 요금제 (멤버십 포함가)
| 데이터 | 월 요금 | 통신 요금 | 카카오멤버십 |
|---|---|---|---|
| 5GB | 5,900원 | 1,000원 | 4,900원 |
| 30GB | 16,000원 | 11,100원 | 4,900원 |
| 50GB | 23,000원 | 18,100원 | 4,900원 |
| 100GB | 37,000원 | 32,100원 | 4,900원 |

음성·문자 제공량, 소진 후 속도는 프로토타입 가정값입니다.

## 카카오멤버십 혜택 구성 (membership.kakao.com 상품구성 준용)
- 선택 혜택(매월 1개): 이모티콘 플러스 / 톡클라우드 130GB
- 적립: 쇼핑포인트 0.5~5%(월 최대 2만P), 카카오페이포인트 0.5~1%·오프라인 0.5~2%(월 최대 5만P)
- 실속: 카카오페이지 2,000캐시, 멜론 스트리밍 라이트 할인, 카카오페이증권 매도수수료 캐시백 최대 4,900원, 액정보험 최대 7만원
- 첫 만남: 국내주식 1주(4,900원 상당), 멜론캐시 총 6,000원
